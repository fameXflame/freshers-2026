## ✨ Features
- **Modern Glassmorphic Dark UI**: Built with a sleek midnight aesthetic, neon gradients, and festive accents.
- **Direct Razorpay Integration**: Instant payment button with visual feedback and celebration confetti.
- **Dynamic QR Code Modal**: Scan & Pay directly with Google Pay, PhonePe, Paytm, or any UPI app.
- **Copy & Share**: Quick button to copy link with toast notification, optimized for WhatsApp & Telegram sharing.
- **Transparent Budget Breakdown**: Clear visual breakdown of fund allocations (DJ, Food, Venue, Titles/Gifts).
- **Interactive FAQ**: Handles common payment queries and troubleshooting steps.
- **Mobile First**: 100% responsive and fast on any mobile device or browser.

## 🚀 How to Run & Preview Locally

### Option 1: Just Double Click
Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Brave).

### Option 2: Run via Local Server (Recommended for testing)
If you have Python installed:
```powershell
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

If you have Node / npx installed:
```powershell
npx serve
```

## 🌐 How to Deploy for Free (To share with your batch)

### Deploy to GitHub Pages (2 Minutes)
1. Create a repository on GitHub (e.g., `iiitb-freshers-fund`).
2. Push this folder to the repository.
3. Go to **Settings > Pages > Branch: main / root > Save**.
4. Your page is live at `https://<your-username>.github.io/iiitb-freshers-fund/`!

### Deploy to Vercel (1 Minute)
1. Run `npx vercel` in this folder OR drag-and-drop the folder into [vercel.com](https://vercel.com).
2. Get an instant custom domain like `https://freshers26-iiitbhopal.vercel.app`.
